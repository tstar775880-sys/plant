# Plant Hub - 台灣賞花與植物養護系統

[Plant Hub](https://github.com/tstar775880-sys/plant.git) 是一個專為台灣賞花迷與園藝養護者打造的網頁應用系統。

## 核心功能

1. **台灣賞花指南 & 行程規劃 (flower-guide.html)**
   - 台灣 1-12 月四季賞花地圖與花期時間軸。
   - **花種與品種細分**：
     - 櫻花：山櫻花(1-2月)、八重櫻(2-3月)、吉野櫻(3-4月)、富士櫻(2-3月)。
     - 梅花：角板山白梅(12-1月)、綠萼梅(1-2月)。
     - 其他：油桐花、繡球花、金針花。
   - **全台賞花名勝景點庫**：陽明山、武陵農場、阿里山、南投信義梅園、竹子湖等。
   - **出遊行程規劃器 (Itinerary Planner)**：排定假期賞花路線與列印功能。

2. **我的植物園 & 澆水日誌 (my-garden.html)**
   - **植物庫存管理**：登記名稱、品種、地點、自訂給水週期（如 3天/5天/7天）。
   - **今日給水任務與動態勾選**：依自訂週期自動算出待給水植物，一鍵勾選同步更新上次給水日並記錄日誌。
   - **養殖問題與失敗經驗帳簿**：紀錄水加太多爛根、施肥、病蟲害檢討與經驗心得。
   - **養護百科手冊**：熱門植物光照與土壤建議。

3. **設計與規範**
   - **無 Icon / 無 Emoji 規範**：全站純粹使用文字階層、質感 CSS Badges 徽章與現代排版。
   - **測試檔案規範**：所有測試用檔案統一以 `test_*` 命名。
   - **開發紀錄**：詳見 [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md)。
